A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page on the user's screen.

History

The first web browser, called WorldWideWeb, was created in 1990 by Tim Berners-Lee.

Function

The purpose of a web browser is to fetch content from the World Wide Web or from local storage and display it on the user's device.
